# データモデル概要

## 保存単位

| 保存先 | 主な用途 | 代表データ |
| --- | --- | --- |
| `matchmaking_users` | ユーザ一覧とプロフィール管理 | ユーザ情報、いいね、マッチ状態 |
| `matchmaking_session` | 現在のログイン状態の保持 | 現在ユーザのスナップショット |
| `matchmaking_chat_<matchKey>` | マッチ相手ごとのチャット履歴 | `matchKey` ごとのメッセージ配列 |
| `matchmaking_chat_event` | BroadcastChannel未対応時の更新通知 | 新着メッセージ / 既読イベント |

```mermaid
    string matchKey FK

  USER_RELATION {

    string toUserId FK
    string relationType
  }

  MESSAGE {
    string id PK
    string senderId FK
    string receiverId FK
    string text
    number timestamp
    string matchKey FK

  }

  CHAT_EVENT {
    string storageKey PK
    string type
    string matchKey FK

    string readBy FK
    number timestamp

  USER o|--|| SESSION : current_session_snapshot
  USER ||--o{ THREAD_MEMBER : participates
  CHAT_THREAD ||--o{ THREAD_MEMBER : has_members
  USER ||--o{ MESSAGE : sends
  USER ||--o{ MESSAGE : receives
  CHAT_THREAD ||--o{ MESSAGE : contains
  CHAT_THREAD ||--o{ CHAT_EVENT : emits
  USER ||--o{ USER_RELATION : from_user
  USER ||--o{ USER_RELATION : to_user
```

## 補足

- `User.matches` は相互いいね成立後の相手IDを保持します。
- `likedUserIds` と `superLikedUserIds` は送信済みの反応を重複なく管理します。
- `matchmaking_session` はユーザごとのセッション一覧ではなく、現在のアクティブセッション1件を保持します。
- `Session` は保存時点のユーザ情報をそのまま保持するスナップショットです（実装では `snapshotJson` 相当）。
- `matchKey` は2ユーザIDをソートして `-` 連結した会話スレッドIDです。
- `Message.type` は通常送信時に `message` を保持し、既読通知は `ChatEvent.type = read` で表現します。
- `Message.isRead` は受信者がチャットを開いたタイミングで `true` になります。
- 初期サンプルメッセージには `id` `isRead` `type` が含まれない場合があります。
- 既読同期時は `type: read` の通知イベントを発行します。
- 1つの `ChatThread` の参加者は常に2ユーザです。
- 各 `Message` には送信者と受信者の2ユーザが関与します。
- `USER_RELATION.relationType` は `like` `superLike` `match` を想定した論理表現です。
- 実装では `likedUserIds` `superLikedUserIds` `matches` を `USER` レコード内のID配列として保持し、`USER_RELATION` は持ちません。
- 実装では `THREAD_MEMBER` テーブルを持たず、`matchKey` から参加者ペアを表現します。
- `ChatEvent` は個々の `Message` ではなく、`ChatThread` 単位の更新通知を表します。
- チャット通知は `BroadcastChannel` を優先し、未対応環境では `storage` イベントで同期します。
- 日本語ラベル版は英語版と同じ構造で、テーブル名・属性名を日本語化しています。
- 利用環境の Mermaid `erDiagram` パーサでは関係行の `:` が必須のため、日本語版の関係ラベルは簡易英字で最小限にしています。
