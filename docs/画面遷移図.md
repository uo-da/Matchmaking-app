# 画面遷移図

```mermaid
flowchart TD
  Start[起動] --> Login[ログイン画面]
  Login -->|GitHub名を入力してログイン| AgeCheck[年齢確認画面]
  Login -->|未入力時は再入力| Login

  AgeCheck -->|18歳以上を確認| ProfileCheck{プロフィール必須項目は入力済みか}
  AgeCheck -->|確認待ち| AgeCheck

  ProfileCheck -->|未入力| Profile[プロフィールタブ]
  ProfileCheck -->|入力済み| Users[カード一覧タブ]

  subgraph MainArea[メイン画面]
    direction TB
    Users
    MatchTab[マッチタブ]
    Profile[プロフィールタブ]
    Settings[設定タブ]
  end

  Users -->|LIKE / スーパーライク / 次へ進む| Users
  Users -->|巻き戻し| Users
  Users -->|Boostデモ表示| Users
  Users -->|相手が通常いいね済みで相互成立| MatchModal[マッチ成立モーダル]
  MatchModal -->|メッセージを送る| Chat[チャット画面]
  MatchModal -->|後で| Users

  Users -->|タブ切り替え| Profile
  Users -->|タブ切り替え| MatchTab
  Users -->|タブ切り替え| Settings

  Profile -->|保存| Profile
  Profile -->|タブ切り替え| Users
  Profile -->|タブ切り替え| MatchTab
  Profile -->|タブ切り替え| Settings

  Settings -->|条件変更| Settings
  Settings -->|タブ切り替え| Users
  Settings -->|タブ切り替え| MatchTab
  Settings -->|タブ切り替え| Profile

  MatchTab -->|検索| MatchTab
  MatchTab -->|相手を選択| Chat
  MatchTab -->|タブ切り替え| Users
  MatchTab -->|タブ切り替え| Profile
  MatchTab -->|タブ切り替え| Settings

  Chat -->|メッセージ送信| Chat
  Chat -->|閲覧時に既読化| Chat
  Chat -->|タブ切り替え| Users
  Chat -->|タブ切り替え| MatchTab
  Chat -->|タブ切り替え| Profile
  Chat -->|タブ切り替え| Settings
  MainArea -->|ヘッダーのログアウト| Login
```

## 補足

- 実装上は、未ログイン時はログイン画面、年齢未確認時は年齢確認画面、確認済みならメイン画面を表示します。
- 年齢確認後、必須プロフィール（技術スタックと経験年数）が不足している場合はプロフィールタブへ誘導します。
- メイン画面の初期表示はカード一覧タブです。
- メイン画面では「カード」「マッチ」「プロフィール」「設定」をタブで切り替えます。
- チャット画面は下部ナビゲーションから他タブへ移動できます。
- マッチ成立モーダルは、相手の `likedUserIds` に現在ユーザIDが含まれる場合に表示されます。
- マッチ成立後は、モーダルを経由せずマッチタブからチャットへ入るケースもあります。
