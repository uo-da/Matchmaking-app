# 機能一覧

## 概要

エンジニア向けマッチングアプリのMVPで提供する主要機能を、利用者の操作順に沿って整理しています。

## 一覧

| 分類 | 機能 | 内容 |
| --- | --- | --- |
| 認証 | ローカルログイン | GitHubユーザ名を入力し、既存ユーザの再利用または新規ユーザ作成でログインします。 |
| 認証 | セッション復元 | ブラウザの保存情報から前回のログイン状態を復元します。 |
| 認証 | ログアウト | 現在のセッションを解除します。 |
| 年齢確認 | 18歳以上の確認 | 利用開始前に年齢を確認します。 |
| 年齢確認 | プロフィール補完誘導 | 年齢確認後、必須プロフィールが不足している場合はプロフィール編集へ誘導します。 |
| プロフィール | プロフィール登録 | 表示名や自己紹介などを登録します。 |
| プロフィール | プロフィール編集 | 登録済みプロフィールを更新します。 |
| プロフィール | 年齢・自己紹介の設定 | 年齢と自己紹介文を管理します。 |
| プロフィール | 技術スタック・趣味の設定 | 技術タグと趣味情報を登録します。 |
| プロフィール | GitHubの草表示 | プロフィール画面でGitHubの活動イメージを表示します。 |
| ユーザ探索 | カード表示 | Tinder風カードUIで候補ユーザを表示します。 |
| ユーザ探索 | スワイプ操作 | 右スワイプでLIKE、左スワイプで次のカードへ進みます。 |
| ユーザ探索 | カード操作ボタン | LIKE、NOPE、スーパーライク、巻き戻し、Boostをボタン操作できます。 |
| ユーザ探索 | 被いいね表示 | 相手からいいね済みの場合、カード上にバッジを表示します。 |
| ユーザ探索 | 条件設定 | 設定タブで技術タグの部分一致文字列と最小経験年数を変更できます。 |
| ユーザ探索 | 巻き戻し | 直前に見ていたカード位置へ戻れます。 |
| ユーザ探索 | Boostデモ | Boostボタン押下時に案内アラートを表示します。 |
| マッチング | いいね送信 | 気になるユーザへ通常のいいねを送ります。 |
| マッチング | スーパーライク送信 | 強い関心を示すスーパーライクを送ります。 |
| マッチング | 相互いいねでマッチ成立 | 双方の意思が一致したらマッチ状態にします。 |
| マッチング | マッチ成立モーダル | 相手が通常いいね済みだった場合に、相手プロフィール画像付きモーダルを表示します。 |
| マッチング | マッチ一覧表示 | 成立済みのマッチ相手を一覧表示します。 |
| マッチング | マッチ検索 | マッチ一覧で表示名や自己紹介を検索できます。 |
| チャット | メッセージ送受信 | マッチ済みユーザと、ブラウザ内ストレージ同期ベースで会話します。 |
| チャット | 既読管理 | チャット画面を開いた時に受信メッセージを既読化します。 |
| チャット | 未読件数表示 | マッチ一覧に未読件数バッジを表示します。 |
| チャット | 既読表示 | 自分が送信したメッセージの既読状態を表示します。 |
| チャット | 通知同期 | BroadcastChannel または localStorage を使って更新を同期します。 |
| チャット | 未読や更新の反映 | 新着メッセージや変更を画面へ反映します。 |

## 補足

- 画面遷移の起点はログイン画面です。
- 年齢確認を完了しないとメイン機能には進めません。
- プロフィールの必須項目は技術スタック1件以上と経験年数です。
- マッチ成立後にチャット機能が利用可能になります。
- メイン画面は「カード」「マッチ」「プロフィール」「設定」の4タブ構成です。
- ログインは外部認証連携ではなく、ローカルデータを使ったデモ実装です。
